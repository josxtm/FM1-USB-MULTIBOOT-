# FM1 MULTIBOOT OS — Cover Flow simulator A1

A standalone **host-browser visual prototype** of the intended 240 x 240 FM1 menu. NOT a bootloader, APK or firmware; no USB, Flash, SD access or actual image launch.

## Run on an Android tablet

1. Open GitHub Actions > **FM1 Cover Flow prototype** for the branch feat/fm1-coverflow-architecture.
2. Download the **FM1_CoverFlow_Prototype_A1** ZIP artifact.
3. Extract the ZIP keeping **index.html and core.js in the same folder**.
4. Open simulator/index.html from a browser or compatible local HTML viewer.
5. Use OCT- / OCT+ / PLAY / REC buttons on screen. Keyboard arrows / Enter / Escape also work.
6. Toggle the mock microSD checkbox to verify the missing-card/recovery experience.

If the Android file viewer prevents local scripts from loading, use a simple local HTTP static-file viewer; the two files can also be hosted together on GitHub Pages once enabled. Do not attempt to install the HTML on the synthesizer.

## Expected interactions

- OCT+: move one cover right (wrap at end).
- OCT-: move left (wrap).
- PLAY: displays **ARRANQUE BLOQUEADO**. Never launches anything.
- REC: dismisses overlay or shows a demo recovery screen.
- Remove mock microSD: screen shows **SIN MICROSD**.
- Restore microSD: normal selection resumes.

All covers are original abstract demo art generated by the browser Canvas API. The labels DARK-1 / ORIGINAL / FELUCCA / SLOOP are examples, not tested firmware images or downloadable binaries.

## Developer check

With Node.js 22:

    node --test tests/coverflow.test.cjs

This checks the pure selection reducer. GitHub Actions packages the browser files as a downloadable artifact.

See ../docs/FM1-MULTIBOOT-ARCHITECTURE.md for the intended hardware architecture and unresolved USB/VBUS and firmware execution constraints.
